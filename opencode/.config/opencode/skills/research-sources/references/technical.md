# Technical research

## Preferred sources

* Official documentation, changelogs, release notes, and maintainer guidance — establish supported behavior and version changes.
* [GitHub](https://github.com/) issues, discussions, releases, and source code — investigate reports, fixes, and implementation details.
* [Stack Overflow](https://stackoverflow.com/) and relevant [Stack Exchange](https://stackexchange.com/) communities — find focused questions and competing solutions.
* Maintainer blogs, technical forums, and practitioner write-ups — find explanations and reproducible examples; verify against current documentation when possible.
* [Hacker News](https://news.ycombinator.com/), [Dev.to](https://dev.to/), and topic-specific communities — gather experiences and leads when official information is incomplete.

## Search and assess

* Include exact error text, versions, platform details, and alternative descriptions of the problem in queries.
* Search both the symptom and possible fixes. Compare open and closed issues, and check whether a fix reached a release.
* Check the dates, versions, and conditions behind accepted answers and workarounds before recommending them.
* Distinguish an official fix from a community workaround, and link directly to the documentation, issue, answer, or code supporting each claim.
