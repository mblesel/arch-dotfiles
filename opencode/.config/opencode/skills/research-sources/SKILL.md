Read only the references relevant to the question:

* `references/academic.md` — papers and scholarly evidence.
* `references/general.md` — news, organizations, products, public discussion, and other general topics.
* `references/technical.md` — software documentation, issues, and technical Q&A.

Paths are relative to this skill's directory. Use more than one reference for mixed topics. These sites are starting points, not a checklist to search on every task. Prefer original documents or firsthand accounts when available, and check what a source actually establishes before citing it.
